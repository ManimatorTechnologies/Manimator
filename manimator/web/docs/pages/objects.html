Adding objects

Press + in the Objects panel to see Manim's objects in groups: Shapes, Arcs & angles, Lines, Text, Tables, Graphs, Media (pictures and SVG files), Helpers, Groups and 3D, plus your customizations under Custom. Search them by name.

  • Click an object, then click the canvas where it should go. You can also drag it onto the canvas.
  • Some objects attach to another one, such as braces and labels. Select that object first, then add them.
  • Adding a 3D object turns the scene into a 3D scene.

Moving and arranging

  • Drag the selected object on the canvas, or move it with the arrow keys (0.1 units, or 0.5 with Shift). Hold Shift while dragging to switch snapping to the grid on or off.
  • The buttons above the Objects list bring the object forward or send it backward (which is drawn on top), duplicate it (Ctrl+D) and delete it (Del).
  • Double-click a name in the list to rename it.

Changing objects

Select an object to see it in the Inspector:

  • Name is its variable name in the Python code.
  • At start: Visible objects are on screen when the scene begins. Hidden ones wait until an animation brings them in.
  • Properties holds the object's own settings, its Style (colors, line width, fill) and its Placement (position, rotation, scale and layer).

To change a number quickly, drag its label sideways.

Methods

On the Methods tab, press Add Method to run one of Manim's methods on the object, such as To corner or Next to. Methods run once, top to bottom, right after the object is made.

Scenes

The tabs along the bottom are the project's scenes, and each becomes its own video. Press + to add one, drag a tab to reorder it, and right-click it to duplicate, move or delete it.

Click an empty part of the canvas to see the scene in the Inspector: its name, the background color and the scene type.

Scene types

The type decides what the camera can do, and which scene actions you can animate.

Scene typeWhat it gives you
SceneA fixed camera looking at the flat scene.
MovingCameraSceneA camera that can pan and zoom during the video.
ZoomedSceneA moving camera plus a magnifying lens shown in a picture-in-picture display.
VectorSceneA grid for drawing vectors, with î and ĵ.
LinearTransformationSceneA grid that matrices and functions transform, carrying vectors and shapes along.
ThreeDSceneA 3D camera that can tilt, turn, spin and fly around.
SpecialThreeDSceneA 3D scene with Manim's preset camera angle.
