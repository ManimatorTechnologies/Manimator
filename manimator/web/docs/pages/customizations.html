Customizations need an account.

Using customizations

A customization is one object or one animation, written in code. Upload a .manimkit file on the Customizations page, and it appears in the editor's Custom group, next to Manim's own objects and animations.

  • Add other people's customizations from the Gallery.
  • A customization's More menu uploads a new version of it (projects keep the version they were made with) or makes it public. Each one is reviewed before it joins the gallery.

Limits

Free keeps up to 5 customizations, Pro up to 20 and Max up to 100 (each with all its versions). Deleting one takes it off your list and out of the editor, but projects that already use it keep working.

Writing a customization

You write a customization twice: in JavaScript, which Manimator runs to draw it in your browser, and in Python, which Manim runs when you download a project as Python. Both are written the way Manim's own classes are.

Start from an example: Battery (an object) or Pop in (an animation). A .manimkit file is a zip file; unzip one to see its parts.

What's in a .manimkit file

FileWhat it is
manifest.jsonIts name, kind, class name and settings (below).
kit.jsThe class Manimator draws, in JavaScript (up to 256 KB).
kit.pyThe same class for Manim, in Python (up to 256 KB).
README.mdOptional: how to use it.

Zip the files (or a folder holding them) and give the file the .manimkit extension. The whole file can be up to 1 MB.

manifest.json

{
  "manimkit": 1,
  "name": "Battery",
  "kind": "object",
  "class": "Battery",
  "version": "1.0",
  "description": "A battery whose fill shows its charge",
  "license": "MIT",
  "style": "none",
  "params": [
    {"name": "charge", "kind": "float", "default": 0.7,
     "min": 0, "max": 1, "step": 0.05, "slider": true, "label": "Charge"}
  ]
}
  • kind: "object" or "animation".
  • class: the class name in both files, in PascalCase. It can't be one of Manim's own names.
  • version: your label for this version.
  • params: the settings the editor shows, up to 20. Each is passed to your class by its name. Kinds: float, int (with min, max, step, slider), bool, color, str, text, font, angle (degrees), point and vector ([x, y]), direction ("UP", "DL"…), and enum (with choices). Each may have a default, a label and a tooltip.
  • Objects: style is which color controls the editor shows: "none" (your object keeps its own colors), "shape" (stroke and fill), "line" or "text".
  • Animations: run_time (seconds), and "introducer": true if it brings its object onto the screen (like FadeIn) or "remover": true if it takes it away (like FadeOut). Your class must do the same (introducer=True in Python).

kit.js

Import what you need from "manimator", the only thing kit.js may import: every Manim object and animation class, the directions and constants (UP, RIGHT, PI, DEGREES…), the named colors as hex strings (GREEN, BLUE_C…), the rate functions, and vector helpers for what Python writes with operators: mul(RIGHT, 2) for RIGHT * 2, add(a, b) for a + b.

import {
  GREEN, LEFT, RIGHT, Rectangle, RoundedRectangle, VGroup, WHITE, mul,
} from "manimator";

export default class Battery extends VGroup {
  static SIG = ["charge"]; // Battery(0.5) means charge=0.5, as in Python

  __init__({ charge = 0.7, ...kw } = {}) {
    super.__init__(kw);
    const body = RoundedRectangle.make({
      width: 2, height: 1, corner_radius: 0.12, color: WHITE,
    });
    const fill = Rectangle.make({
      width: 1.8 * charge, height: 0.8, stroke_width: 0, fill_color: GREEN, fill_opacity: 1,
    });
    fill.align_to(body, LEFT).shift(mul(RIGHT, 0.1));
    this.add(body, fill);
    return this;
  }
}
  • Export the class as export default.
  • Classes are made like Python's: Circle.make({ radius: 2 }) is Circle(radius=2). Their setup goes in __init__, which takes the arguments as one object and returns this. Methods take the same arguments as in Python, in the same order: a.next_to(b, RIGHT, 0.5).
  • An animation extends Animation and changes this.mobject in interpolate_mobject(alpha); apply this.rate_func(alpha) yourself, as in Manim. See the Pop in example.
  • kit.js runs in a sandbox that can't reach the network, the page or the account: it can only draw.

kit.py

from manim import *


class Battery(VGroup):
    def __init__(self, charge=0.7, **kwargs):
        super().__init__(**kwargs)
        body = RoundedRectangle(width=2, height=1, corner_radius=0.12, color=WHITE)
        fill = Rectangle(
            width=1.8 * charge, height=0.8, stroke_width=0, fill_color=GREEN, fill_opacity=1
        )
        fill.align_to(body, LEFT).shift(RIGHT * 0.1)
        self.add(body, fill)

It goes into the customizations folder of a project's Python download, and scene.py imports it. Manimator never runs it. Keep both files drawing the same thing: what you see in Manimator is the JavaScript, what Manim renders is the Python.
