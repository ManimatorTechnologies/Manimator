Manimator works on Manim, the animation engine behind many math videos. You don't need to install anything or write any Python: everything happens in the browser.

First steps

  1. Press Start Creating on the home page to open the app.
  2. Press New Project.
  3. Press + in the Objects panel, pick an object, and click the canvas to place it. See Scenes and objects.
  4. With the object selected, press + in the Animation panel and pick an animation. See Animation.
  5. Press Space to play it, then Render scene to make the video. See Videos and downloads.

Guests and accounts

You can try Manimator as a guest. Sign up to keep your work in an account (your guest projects come with you), and to use presentations and customizations. Each plan's limits are on the Pricing page.

Projects

The app opens on your Projects. Press New Project to start one, or click a project to open it. Search with the box above the list (press / to jump to it), and switch between cards and a list. Each project's More button (the three dots) renames or deletes it.

Your work is saved as you edit, so closing the tab loses nothing. In the editor, click Manimator in the top left (or File → All Projects) to come back to your projects.

The editor

PartWhat it does
Top barThe File, Edit, View, Render and Help menus, undo and redo, and buttons to download the project, render videos and download Python.
Objects (left)Everything in the current scene. Add objects with +.
Canvas (middle)The scene's frame. Click an object to select it, then drag it to move it.
Inspector (right)The selected object's settings, or the scene's when nothing is selected.
Animation (bottom)The steps that play, one after another, as a timeline.
Scene tabs (very bottom)The project's scenes. Each scene becomes its own video.

Drag the lines between the panels to resize them. View → Reset panel sizes puts them back.
