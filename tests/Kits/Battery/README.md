# Battery

A battery icon whose fill shows how charged it is. Set **Charge** from 0 (empty) to 1 (full): the fill is green
from half charge up, yellow below that, and red below a fifth.

## Animations

- **Pop in** brings the battery in by growing it from nothing to a little past its full size, then settling.
  **Bounce** sets how far past full size it goes (0 for none).
