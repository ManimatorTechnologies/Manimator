# Contributing

Bug reports and ideas are welcome as GitHub issues. For a larger change, open an issue first so we can agree on it.

## Before you send a pull request

- Run the tests (see the README) and add one for what you changed.
- Keep to the code's style: small functions, comments that say why, no new dependencies without a good reason.
- The editor's knowledge of Manim lives in `manimator/registry/` as data; new objects, methods and animations go there.
